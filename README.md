# Crewster Policies

Public legal documents for the Crewster mobile app
(iOS + Android) operated by **Lizentics** (Spain).

Crewster source code lives in the private
[Lizentics-Crewster/Crewster](https://github.com/Lizentics-Crewster/Crewster)
repo. This repo exists to host the legal documents at a public,
stable URL via GitHub Pages.

## Documents

- [Privacy Policy](./privacy-policy.md) — what data Crewster
  collects + why + your GDPR rights.
- [Terms of Service](./terms-of-service.md) — usage terms +
  AS-IS disclaimer + governing law.

## Hosted versions

Once GitHub Pages is enabled on this repo:

- https://lizentics-crewster.github.io/crewster-policies/privacy-policy
- https://lizentics-crewster.github.io/crewster-policies/terms-of-service

## Updating

These files are mirrors of the canonical source documents in the
private Crewster repo at `docs/privacy-policy.md` +
`docs/terms-of-service.md`. To update:

1. Edit the canonical source in the private repo.
2. Commit + push there.
3. Copy the updated files to this repo + push.
4. Bump the `Last updated` date inside the document.

A future automation could sync these via GitHub Actions on
private-repo push; deferred to post-MVP.
